# AutoModel
**Input any CSV, and what to predict, and get a trained model back.**

AutoModel is a tool that ingests an arbitrary CSV file, lets you choose the target column(s) you want to predict and ignore, automatically infers the problem type (regression vs. classification), builds and trains a neural network, and exports the trained model for reuse.
